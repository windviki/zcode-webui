ZCode 凭据导出工具

在你已经登录 ZCode 的电脑上打开本页面（完全本地运行，凭据不会离开本机，除非你主动复制）。它会把桌面端凭据文件解密成明文 JSON，供 zcode-webui 的「导入凭据」使用。

  1. 选择桌面端的凭据文件（或直接粘贴内容）：
    • Windows：%USERPROFILE%\.zcode\v2\credentials.json
    • macOS / Linux：~/.zcode/v2/credentials.json
  2. 填写本机的 platform / 主目录 / 用户名（解密密钥由这三者派生；已按当前系统预填猜测值）。
  3. 点击「解密并生成」，把输出的 JSON 复制到 zcode-webui 登录页的「导入凭据」框。
